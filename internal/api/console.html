接入你的 AI 工具

yogod 只认一套标准事件。让工具读它自己的官方 hook 文档,把原生事件显式映射过来;名字怎么叫都行,不用改 yogod。
1推荐:把这段话原样发给你的 AI 工具 —— 里面写了标准事件、两种接入方式、隐私边界和验证方法,工具自己就能装好:
加载中…
2手动:运行 yogod hook install --agent <名字> --force-event 打印配置片段(事件名直接写进命令行,不依赖 payload),自己合并;加 --config <路径> --write 则直接合并,先备份。回调式工具直接 POST /api/events。
3验证:发一条消息 —— 会话列表出现你的工具、点阵进入执行中,就成了。直接 POST 的话,返回 JSON 里的 state 就是当前灯态。事件只取白名单元数据,prompt、密钥、对话正文一律不碰,有测试盯着。
