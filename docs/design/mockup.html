接入你的 AI 工具

1yogod 只认一套标准事件:让工具读它自己的官方 hook 文档,把原生事件显式映射过来。
2推荐把接入指令原样发给 AI 工具,它自己就能配好;手动则运行:
# 打印配置片段(事件名写进命令行;加 --write 直接合并,只增不改)
yogod hook install --agent cursor --force-event
3事件只取白名单元数据 —— prompt、密钥、对话正文一律不碰,有测试盯着。
